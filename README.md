# Portfolio Website

A modern, responsive portfolio website showcasing projects, experience, and professional information. Built with React, Vite, and React Bootstrap using a modular component-based architecture. Features a clean UI with custom SCSS styling and section-based navigation.

## Setup

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start development server**
   ```bash
   npm run dev
   ```

3. **Build for production**
   ```bash
   npm run build
   ```
